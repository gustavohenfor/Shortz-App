<h2>🎬 Shortz-App</h2>

<p>
  Aplicação web de vídeos desenvolvida com Node.js, Express, EJS e MySQL,
  envolvendo autenticação de usuários, comentários, curtidas, playlists
  e gerenciamento de conteúdo.
</p>
